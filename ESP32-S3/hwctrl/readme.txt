This is a small Arduino project that uses a ESP32-S3 to control the circulation
pump on a solar hot water system. It requires some additional electronics and 
a ads1115 A/D converter to read two Pt1000 temp sensors (collector and Tank)
detailed here. Arduino provide a very easy to use system to program the ESP32,
a superficially simple software stack supported by the ESP32 manufactors and
easy to keep up to date. Important for a very part time C programmer like me.
I'd prefer to work in Pascal but the software stack is just not there.
